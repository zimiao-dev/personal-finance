## 1. 项目背景

为了帮助用户更好地了解个人财务状况，系统提供收入和支出记录功能。

系统通过保存交易记录、提供查询和统计功能，帮助用户分析自己的收支情况。

V1版本主要关注个人日常收支管理，不考虑复杂财务分析功能。

## 2. 用户角色

###  User

个人财务管理用户。

V1版本限制：

- 单用户使用
- 本地运行
- 不提供登录和权限管理

## 3. 用户需求

说明：

- 交易类型(type)：表示收入或支出
- 分类(category)：表示交易所属类别，如餐饮、交通、工资

### 添加账单

作为一个用户，

我希望记录收入或是支出，

从而保存我的财务记录。

验收标准：

- 用户可以输入金额
- 用户可以选择收入或者支出类型
- 用户可以输入分类
- 用户可以输入日期
- 用户可以输入账单备注
- 金额必须为正数
- 金额格式错误时提示用户重新输入
- 收入/支出类型不能为空
- 保存成功后返回提示

### 查看账单

作为一个用户，

我希望可以查看过往的账单记录，

了解我过去的收支情况。

验收标准：

- 用户可以查看所有账单记录
- 每条记录显示金额、类型、分类、日期、备注
- 如果没有记录，提示暂无账单

### 修改账单

作为一个用户，

我希望可以修改有误的账单记录，

以保证账单的准确性。

- 用户通过账单ID指定需要修改的账单记录
- 系统展示当前的账单信息
- 用户确认修改目标记录
- 用户可以修改当前账单的金额、类型、分类、日期、备注
- 修改后的金额必须为正数
- 修改后的日期格式必须正确
- 修改成功后保存新的账单信息
- 用户输入不存在的账单ID，系统提示记录不存在

### 删除账单

作为一个用户，

我希望可以删除一个错误的账单记录，

以保证账单的数据正确。

验收标准：

- 用户通过账单ID指定需要删除的账单记录
- 系统展示当前的账单信息
- 用户确认是否删除账单
- 删除成功后移除账单记录，已有账单ID不重新编号
- 用户输入不存在的账单ID，系统提示记录不存在

### 查询账单

作为一个用户，

我希望可以按照日期或者分类查询账单，

以快速查找账单。

验收标准

- 用户可以选择按照日期范围或者账单分类进行查询
- 用户可以单独使用日期或分类查询，也可以组合查询
- 用户可以输入日期范围或者分类名称
    - 日期格式必须符合系统要求
    - 分类名称不能为空
- 系统展示符合条件的全部账单记录，包括：
    - 金额
    - 类型
    - 分类
    - 日期
    - 备注
- 当查询结果为空时，系统提示暂无符合条件的账单记录
- 用户输入非法查询条件时，系统提示输入错误

### 统计账单

作为一个用户，

我希望可以统计某个时间段内的收入与支出，

从而了解自己的总体财务状况。

验收标准：

- 用户可以输入统计日期范围，未输入时默认统计全部账单
- 系统展示指定日期范围内：
  - 总收入金额
  - 总支出金额
  - 收支差额
- 当统计范围内没有账单数据时，系统提示暂无统计数据
- 用户输入非法日期格式时，系统提示输入错误

## 4. V1 功能列表

| 功能 | 描述 |
|------|------|
| 添加账单 | 创建收入/支出记录 |
| 查看账单 | 查看所有记录 |
| 查询账单 | 按日期、分类筛选 |
| 修改账单 | 更新记录 |
| 删除账单 | 删除记录 |
| 收支统计 | 收入、支出汇总 |

## 5. 非功能需求

### 数据保存

程序关闭后，数据不会丢失；

使用SQLite保存。

### 输入校验

- 金额必须为数字
- 金额大于0
- 日期格式正确

### 错误处理

程序不能因为用户输入格式错误而直接退出，而是提示相应错误信息。

### 项目结构

代码按照功能模块划分，避免所有逻辑集中在单个文件。

### 数据安全

程序异常退出时，保证已有数据不会损坏。
