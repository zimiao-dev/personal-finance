## 1. 项目背景

为了帮助用户更好地了解个人财务状况，系统提供收入和支出记录功能。

系统通过保存交易记录、提供查询和统计功能，帮助用户分析自己的收支情况。

V1版本主要关注个人日常收支管理，不考虑复杂财务分析功能。

## 2. 用户角色

### User

个人财务管理用户。

V1版本限制：

- 单用户使用
- 本地运行
- 通过命令行界面（CLI）交互
- 使用SQLite保存数据
- 不提供登录和权限管理

## 3. 用户需求

说明：

- 交易类型(type)：表示收入或支出
- 分类(category)：表示交易所属类别，如餐饮、交通、工资

### 添加账单

作为一个用户，

我希望记录收入或是支出，

从而保存我的财务记录。

验收标准：

- 用户可以输入金额
- 用户可以选择收入或者支出类型
- 用户可以输入分类
- 用户可以输入日期
- 用户可以输入账单备注
- 金额必须能够转换为有限浮点数且大于0
- 收入/支出类型只允许使用income或expense
- 输入校验失败时，系统显示输入错误，结束当前添加操作并返回主菜单
- 保存成功后返回提示

### 查看账单

作为一个用户，

我希望可以查看过往的账单记录，

了解我过去的收支情况。

验收标准：

- 用户可以查看所有账单记录
- 每条记录显示ID、金额、类型、分类、日期、备注
- 如果没有记录，提示暂无账单

### 修改账单

作为一个用户，

我希望可以修改有误的账单记录，

以保证账单的准确性。

- 用户通过账单ID指定需要修改的账单记录
- 系统展示当前的账单信息
- 用户确认修改目标记录
- 用户可以修改当前账单的金额、类型、分类、日期、备注
- 修改后的金额必须为正数
- 修改后的日期格式必须正确
- 修改成功后保存新的账单信息
- 用户输入不存在的账单ID，系统提示记录不存在

### 删除账单

作为一个用户，

我希望可以删除一个错误的账单记录，

以保证账单的数据正确。

验收标准：

- 用户通过账单ID指定需要删除的账单记录
- 系统展示当前的账单信息
- 用户确认是否删除账单
- 删除成功后移除账单记录，已有账单ID不重新编号
- 用户输入不存在的账单ID，系统提示记录不存在

### 查询账单

作为一个用户，

我希望可以按照日期或者分类查询账单，

以快速查找账单。

验收标准：

- 用户可以选择按照日期范围或者账单分类进行查询
- 用户可以单独使用日期或分类查询，也可以组合查询
- 用户可以输入日期范围或者分类名称
    - 日期必须是严格合法的YYYY-MM-DD格式
    - 开始日期不能晚于结束日期
    - 分类名称清理首尾空格后不能为空
- 分类使用清理首尾空格后的值进行精确匹配
- 日期范围包含开始日期和结束日期
- 分类与日期组合查询必须同时满足分类和日期范围条件
- 查询结果按照账单ID降序返回
- 系统展示符合条件的全部账单记录，包括：
    - ID
    - 金额
    - 类型
    - 分类
    - 日期
    - 备注
- 当查询结果为空时，系统明确提示没有符合条件的账单记录
- 用户输入非法查询条件时，系统提示输入错误

### 统计账单

作为一个用户，

我希望可以统计某个时间段内的收入与支出，

从而了解自己的总体财务状况。

验收标准：

- 用户选择a时，统计全部账单
- 用户选择b时，按日期范围统计账单
- 日期范围包含开始日期和结束日期
- 其他输入（包括空输入）会显示输入错误，并结束当前统计操作
- 系统展示所选统计范围内：
  - 总收入金额
  - 总支出金额
  - 收支差额
- 当统计范围内没有账单数据时，系统提示暂无统计数据
- 用户输入非法日期格式时，系统提示输入错误

## 4. V1 功能列表

| 功能 | 描述 |
|------|------|
| 添加账单 | 创建收入/支出记录 |
| 查看账单 | 查看所有记录 |
| 查询账单 | 按日期、分类筛选 |
| 修改账单 | 更新记录 |
| 删除账单 | 删除记录 |
| 收支统计 | 收入、支出汇总 |

主菜单使用1至6选择上述功能，使用0退出系统。

## 5. 非功能需求

### 数据保存

程序关闭后，数据不会丢失；

使用SQLite保存。

### 输入校验

- 金额清理首尾空格后必须能够转换为有限浮点数
- 金额必须大于0
- 类型清理首尾空格并转换为小写后，只允许income或expense
- 分类清理首尾空格后不能为空
- 账单ID必须是大于0的整数
- 日期必须是严格合法的YYYY-MM-DD格式，不仅匹配字符串格式，还必须是真实存在的日历日期
- 开始日期不能晚于结束日期
- 校验失败时抛出ValueError，由主循环显示输入错误，结束当前业务操作并返回主菜单

### 错误处理

程序不会因为ValueError直接退出，而是显示相应的输入错误信息并继续主菜单循环。

主菜单、查询方式或统计方式输入无效时，系统显示错误提示；无效的查询或统计方式会结束当前操作。

### 项目结构

代码按照功能模块划分，避免所有逻辑集中在单个文件。

### 数据安全

数据库写操作通过事务提交。

操作执行失败时，不提交未完成的写入。
